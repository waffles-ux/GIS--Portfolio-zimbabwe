# GIS Portfolio — Zimbabwe Spatial Analysis
## Khanyiso Dube | Agricultural Engineering Student | CUT Zimbabwe

### Projects

**Project 1: Agricultural Suitability Analysis — Mashonaland Central**
Multi-criteria analysis identifying optimal smallholder irrigation zones using water proximity (2km) and road accessibility (5km) buffers.
Tools: QGIS, Buffer, Clip, Intersection
![P1 Map](agricultural_suitability_MC.png)

**Project 2: Water Source Accessibility — Mashonaland Central**
Three-tier accessibility classification (500m/2km/5km) around water sources.
Tools: QGIS, Nested Buffers, Clip
![P3 Map](water_accessibility_MC.png)

**Project 3: Land Use Map — Mashonaland Central**
Classified land use distribution including farmland, forest, residential and industrial zones.
Tools: QGIS, Clip, Categorized Symbology
![P5 Map](land_use_MC.png)

**Project 4: Flood Risk Assessment — Mashonaland Central**
Terrain-based flood risk classification using SRTM DEM elevation thresholds.
Tools: QGIS, Raster Analysis, Slope, Raster Calculator
![P6 Map](flood_risk_MC.png)

**Project 5: Zimbabwe National Agriculture Potential**
National-scale agricultural suitability analysis combining water and road accessibility.
Tools: QGIS, Buffer, Intersection, Reprojection
![P8 Map](zimbabwe_agriculture_final.png)
